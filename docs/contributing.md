# Contributing

Contributions are welcome across model adapters, analyses, visualisations, tests, examples, and documentation. Keep framework-specific dependencies optional and do not commit secrets, datasets, checkpoints, or model weights.

For the development environment, branching workflow, contribution process, testing, and pull-request guidance, see the complete [CONTRIBUTING.md](https://github.com/ChidiebereNjoku/ModelBrief/tree/CONTRIBUTING.md).
